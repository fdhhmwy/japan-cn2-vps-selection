## 日本 CN2 VPS 贵在哪：CN2 GIA、CN2 GT 和三网优化

CN2 是中国电信的下一代承载网（AS4809），相比老的 163 骨干网，拥堵更少、丢包率更低。CN2 内部还分两档：

- **CN2 GIA**：全程走电信高速通道，回国质量最好，价格也最高。
- **CN2 GT**：国际段走 CN2，国内段可能切回 163 骨干网，便宜，高峰期会堵。

这解释了一部分价差。剩下那部分来自联通和移动。只优化电信，联通移动用户照样绕路，所以做国内生意的商家会配三网：电信 CN2 GIA、联通 AS9929、移动 CMI。三条线都要买带宽，成本自然上去了。

同配置的价格差 2-3 倍属于正常范围。DMIT 日本 Premium 的 Pro.TINY 是 1 核 1G / 20G SSD / 500GB，$21.9/月；Evoxt 的 VM-0.75 是 1 核 1G / 10GB / 750GB，$4.99/月。两者都是东京机房，差出来的十几美元买的是回国那段路由。

路由层面，恒创的测评记录显示电信去程走 59.43 的 CN2 节点直连东京、回程全程 CN2；联通去程 CN2、回程直连；移动去程 CMI、回程经 NTT 到香港后直连回国。DMIT 的 Premium 则是三网回程强制 CN2 GIA，去程电信 CN2 GIA、联通 AS9929、移动 CMI。

两条结论对选型有用。电信用户体验最好，纯 CN2 GIA 能把延迟压到 60ms 上下。联通和移动走的是各自的优化线路，并非纯 CN2，延迟落在 50-93ms 区间，可用但不如电信稳定。如果你只知道访客“在国内”，电信占比通常最高，优先保证电信这一段。

作为参照，东京到上海、广州的纯网络延迟本身就在 50-80ms，美国节点是 150-250ms，香港是 30-60ms。日本的价值在于带宽比香港宽松、价格比香港便宜，延迟只比香港高一档。
